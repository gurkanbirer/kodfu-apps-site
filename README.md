# kodfu-apps-site

Public GitHub Pages site: support, privacy and terms pages for the Kodfu UK apps.
URL: https://gurkanbirer.github.io/kodfu-apps-site/<app>/ , /<app>/privacy/ , /<app>/terms/

Each app's session owns only its own folder (`tickover/`, `fareback/`, `bluebell/`, `hivis/`,
`sparkwise/`). Commit and push only your folder. Plain static HTML, en-GB, light/dark, no
trackers, no third-party scripts.
